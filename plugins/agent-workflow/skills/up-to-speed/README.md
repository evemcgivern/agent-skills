# Up to Speed

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

Gets you up to speed on an unfamiliar field in one sitting (roughly 45-90 minutes, shorter on request), one question at a time: the field's map, the 8-10 terms insiders use, the 3-5 ideas that explain most of it, live debates, and a scored exam with no hints. Use with "get me up to speed on", "crash course", "brief me on", or before a meeting in an industry you don't know.

## Install

Copy this complete folder to `~/.claude/skills/up-to-speed/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/up-to-speed/` for personal Codex use. For repository-only use, copy to `.claude/skills/up-to-speed/` or `.agents/skills/up-to-speed/` respectively. See the [collection README](../../../../README.md#install) for current platform notes.
