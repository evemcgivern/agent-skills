# Efficient Frontier

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../../../LICENSE) [![Version](https://img.shields.io/badge/version-0.2.0-informational.svg)](CHANGELOG.md)

Routes model effort across research, coding, testing, and review so strong models handle judgment and cheaper subagents handle volume, including for users with limited quotas. Use when deciding whether to delegate, writing subagent handoffs, or when asked to "save tokens", "use cheaper models", "parallelize this", "fan out subagents", or "stay inside my quota".

## Install

Copy this complete folder to `~/.claude/skills/efficient-frontier/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/efficient-frontier/` for personal Codex use. For repository-only use, copy to `.claude/skills/efficient-frontier/` or `.agents/skills/efficient-frontier/` respectively. Supporting files in this folder may be required. See the [collection README](../../../../README.md) for current platform notes.
