# Analytics Instrumentation

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../../../LICENSE) [![Version](https://img.shields.io/badge/version-0.2.0-informational.svg)](CHANGELOG.md)

PostHog event taxonomy and instrumentation review - object_verb naming, flat property schemas, identify/reset/group calls, PII exclusion, LLM usage events, a starter dashboard set (activation, retention, feature funnel), and a per-feature checklist. Use when instrumenting a new feature, auditing existing PostHog events, or setting up analytics for a new product, e.g. "add tracking", "what events should we fire", "review our PostHog events", "is there PII in analytics".

## Install

Copy this complete folder to `~/.claude/skills/analytics-instrumentation/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/analytics-instrumentation/` for personal Codex use. For repository-only use, copy to `.claude/skills/analytics-instrumentation/` or `.agents/skills/analytics-instrumentation/` respectively. Supporting files in this folder may be required. See the [collection README](../../../../README.md) for current platform notes.
