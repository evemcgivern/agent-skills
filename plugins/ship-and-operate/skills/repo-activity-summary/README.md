# Repo Activity Summary

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../../../LICENSE) [![Version](https://img.shields.io/badge/version-0.2.0-informational.svg)](CHANGELOG.md)

Summarize current GitHub repo activity - open issues, open PRs with check status, recent CI runs, and local branch state - in one report with planning takeaways, via the gh CLI. Use on "activity summary", "what's open", "project status", "progress check", "CI status", or a request to list open issues and PRs.

## Install

Copy this complete folder to `~/.claude/skills/repo-activity-summary/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/repo-activity-summary/` for personal Codex use. For repository-only use, copy to `.claude/skills/repo-activity-summary/` or `.agents/skills/repo-activity-summary/` respectively. Supporting files in this folder may be required. See the [collection README](../../../../README.md) for current platform notes.
