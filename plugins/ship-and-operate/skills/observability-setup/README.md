# Observability Setup

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../../../LICENSE) [![Version](https://img.shields.io/badge/version-0.2.0-informational.svg)](CHANGELOG.md)

Wire a web service for observability sized for a small team - health-check endpoint, uptime checks, log forwarding, error tracking, product analytics, LLM cost tracking, and page-vs-ticket alert thresholds. Examples use Render, Better Stack, Sentry, and PostHog. Use when launching a new service, auditing monitoring on an existing one, or on "set up monitoring", "add a health check", "forward logs", "we get paged too much", or "alert fatigue".

## Install

Copy this complete folder to `~/.claude/skills/observability-setup/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/observability-setup/` for personal Codex use. For repository-only use, copy to `.claude/skills/observability-setup/` or `.agents/skills/observability-setup/` respectively. Supporting files in this folder may be required. See the [collection README](../../../../README.md) for current platform notes.
