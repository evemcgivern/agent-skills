# Word choices

Words that fail the reader or the facts: claims nobody can verify, words that say nothing, and words that overstate. This is a clarity and truthfulness list. It is not a detector-evasion list and not a target style. Flag a listed word only where it is empty or unsupported: "several" with no count in the source, "led" with no source role. Ordinary words used with support are fine. The candidate's own wording, technical terms and dialect outrank this list: do not add a listed word, and if the source resume already uses one, keep it and ask whether to change it. A candidate's own banned words and approved verbs layer on top of this list and outrank it. Never use another person's list.

## Do not add

| Group | Examples | Instead |
|---|---|---|
| Self-description nobody can verify | results-driven, team player, hard worker, detail-oriented, go-getter, self-starter, passionate, dynamic, motivated, strategic thinker, think outside the box, proven track record | The fact it stands for: a scope, a result or a named example. Otherwise cut it. |
| AI-tell verbs and filler | leveraged, utilized, spearheaded, orchestrated, harnessed, fostered, synergy, robust, seamless, cutting-edge, best-in-class, world-class, innovative | The plain verb the source uses (for example used, built, ran). |
| Weak openers | responsible for, helped with, worked on, assisted, involved in, participated in, duties included | The verb for what the candidate did, in the source's words. A duty with no result stays a duty. |
| Vague quantifiers | various, several, numerous, multiple, many, a variety of, etc., and more | The count if the source has one. Otherwise name the items or cut it. |
| Unearned labels | expert, certified, advanced, master, a title word such as senior | The source's exact title and credential name, marked in progress if unearned. |
| Ownership verbs the source does not give | owned, drove, led, managed, architected, delivered | The source's own verb. A team outcome stays a team outcome. |
| Posting words with no source line | any posting term the source does not use and no recorded equivalent covers | Remove it, use the source's own term, or record a same-meaning equivalent. Run `scripts/check_terms.py` to list them. |
| Details the source lacks | the posting's job title as the candidate's specialty line, a location note such as "(remote)", a total-years claim | Use the source's title, location and dates. A length of experience appears only as "since YEAR". |

## Use with care

- A posting term as the label for the candidate's equivalent, only when the meaning is the same in the source and the pair is recorded in the equivalence table.
- Tools, credentials and frameworks in their standard published spelling and capitalization (Power BI, ServiceNow, ISO/IEC 27001), with the full name and acronym each shown once when the source uses both.
