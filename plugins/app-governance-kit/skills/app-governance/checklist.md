# Application governance router checklist

1. Goal confirmed: what the person is deciding and by when [[XW-027]]
2. Skill chosen from the routing table, with the reason stated [[XW-027]]
3. Data the skill needs named and requested, or the demo estate offered [[XW-001]]
4. Chosen skill loaded and followed, including its output rules [[XW-025]]
5. Any second area noticed and offered, not run without asking [[XW-027]]
6. Answer given first, then reasoning, then open decisions [[XW-025]]
7. Every decision marked **Decision needed:** and left to a person [[XW-027]]
8. Routing log row handed to the requester to record, since the router is read-only [[XW-020]]
