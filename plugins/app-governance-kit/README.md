# App Governance Kit

![Version](https://img.shields.io/badge/version-0.1.0-blue) ![Claude Code CLI](https://img.shields.io/badge/Claude%20Code%20CLI-supported-6B4FBB) ![Claude Code Desktop](https://img.shields.io/badge/Claude%20Code%20Desktop-supported-6B4FBB) ![Codex](https://img.shields.io/badge/Codex-supported-111111) ![ChatGPT](https://img.shields.io/badge/ChatGPT-skill%20upload-74AA9C) ![License](https://img.shields.io/badge/license-MIT-green)

Nine portable application-governance skills for application portfolios, AI, access, hardware, and certification preparation.

## The full site: visuals and practice

The skills are one part of the kit. The full site, **[https://evemcgivern.github.io/app-governance-kit/](https://evemcgivern.github.io/app-governance-kit/)**, has the visuals and the hands-on practice that go with them. Start there if you want to see how the pieces fit before installing anything.

| Page | What it has |
|---|---|
| [Practicum](https://evemcgivern.github.io/app-governance-kit/practicum.html) | Seven hands-on governance exercises with self-checking, in the browser |
| [Crosswalk explorer](https://evemcgivern.github.io/app-governance-kit/crosswalk.html) | 29 governance themes mapped across four frameworks |
| [Impact map](https://evemcgivern.github.io/app-governance-kit/impact-map.html) | Every crosswalk theme against every lifecycle stage, by impact |
| [Lifecycle](https://evemcgivern.github.io/app-governance-kit/lifecycle.html) | Six lifecycle stages, each with the governance questions to ask |
| [Field guide](https://evemcgivern.github.io/app-governance-kit/field-guide.html) | Certifications, standards, glossary and data governance, in plain terms |
| [SAM toolkit](https://evemcgivern.github.io/app-governance-kit/sam-toolkit.html) | Eight free templates and checklists for software asset management |
| [Tools](https://evemcgivern.github.io/app-governance-kit/tools.html) | The skills, the router and the study coach, with downloads for each platform |
| [Case studies](https://evemcgivern.github.io/app-governance-kit/case-studies.html) | Anonymized case studies (in preparation) |

The source for the site and the skills lives in [evemcgivern/app-governance-kit](https://github.com/evemcgivern/app-governance-kit). This marketplace carries the skills as a Claude Code plugin.
