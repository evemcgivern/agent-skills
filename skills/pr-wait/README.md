Wait for GitHub PR CI checks to complete, then optionally merge

## Install

Copy this complete folder to `~/.claude/skills/pr-wait/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/pr-wait/` for personal Codex use. For repository-only use, copy to `.claude/skills/pr-wait/` or `.agents/skills/pr-wait/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
