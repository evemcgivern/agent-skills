# Stripe Billing

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

Implement or review Stripe subscription billing for a Next.js App Router product (Checkout, customer portal, webhook handler, plan changes, trials, dunning). Use when adding subscriptions or paywalls to a product or service, when reviewing existing billing code for correctness, or when a webhook/proration/trial bug is reported.

## Install

Copy this complete folder to `~/.claude/skills/stripe-billing/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/stripe-billing/` for personal Codex use. For repository-only use, copy to `.claude/skills/stripe-billing/` or `.agents/skills/stripe-billing/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
