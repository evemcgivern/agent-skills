# Api Design

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

REST conventions for Next.js App Router route handlers — resource naming, versioning, pagination, a standard error envelope, Zod request/response validation, status-code discipline, OpenAPI generation, and API-response scrubbing (no PII/internal IDs/tokens). Use when asked to "design an API route," "add a new endpoint," "review this route handler," or "generate API docs.

## Install

Copy this complete folder to `~/.claude/skills/api-design/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/api-design/` for personal Codex use. For repository-only use, copy to `.claude/skills/api-design/` or `.agents/skills/api-design/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
