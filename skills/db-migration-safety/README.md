# Db Migration Safety

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

Write or review Prisma and Supabase database migrations safely using the expand-contract pattern, idempotent SQL, and batched backfills. Use when adding/changing columns or tables, writing a migration PR, or reviewing one before merge — especially against Neon Postgres or Supabase in production.

## Install

Copy this complete folder to `~/.claude/skills/db-migration-safety/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/db-migration-safety/` for personal Codex use. For repository-only use, copy to `.claude/skills/db-migration-safety/` or `.agents/skills/db-migration-safety/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
