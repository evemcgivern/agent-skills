# Observability Setup

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

Wire a service for observability sized for a small team — Better Stack uptime checks and log drains from Render, error tracking, PostHog product analytics, Render health-check endpoints, and alert thresholds tuned so two humans aren't paged into the ground. Use when launching a new service, adding monitoring to an existing one, or when alert fatigue is a complaint.

## Install

Copy this complete folder to `~/.claude/skills/observability-setup/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/observability-setup/` for personal Codex use. For repository-only use, copy to `.claude/skills/observability-setup/` or `.agents/skills/observability-setup/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
