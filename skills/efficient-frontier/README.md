# Efficient Frontier

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](../../LICENSE) [![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)](CHANGELOG.md)

Route model effort efficiently across research, coding, and review, including for users with limited quotas. Use when deciding whether to delegate routine work, reserve stronger models for judgment, or control model usage.

## Install

Copy this complete folder to `~/.claude/skills/efficient-frontier/` for Claude Code CLI and local Claude Code desktop sessions, or to `~/.agents/skills/efficient-frontier/` for personal Codex use. For repository-only use, copy to `.claude/skills/efficient-frontier/` or `.agents/skills/efficient-frontier/` respectively. Supporting files in this folder may be required. See the [collection README](../../README.md) for current platform notes.
